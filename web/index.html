Email Reply AI Agent

A Gmail agent that decides whether to reply, skip or escalate each incoming email. Rule-based guardrails run first, one LLM call decides, and uncertain mail is handed to a human.

How every email is processed

Five possible outcomes

Safety design

  • Rule-based guardrails run before the LLM (0 tokens)
  • One grounded LLM call, only facts from a business file
  • Draft is re-checked: links, addresses, length, confidence
  • Unsure mail goes to a human, never guessed
  • Built to avoid duplicate replies and reply loops
  • Measured on a small labelled test set
